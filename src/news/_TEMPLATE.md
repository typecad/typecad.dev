Start writing here. Markdown is fully supported:

## Sections

Use `##` for section headings and `###` for sub-sections.

## Lists and code

- Bullet lists work as expected
- So do numbered lists

```ts
// fenced code blocks get a dark block with the site font
const x = 42;
```

Inline `code` gets a muted chip. **Bold**, _italic_, and [links](/) all work.

## Tips

- Set `published: false` to keep a draft out of the news list
- The `date` field (YYYY-MM-DD) controls the ordering — newest first
- The `description` shows under the title on the news index
